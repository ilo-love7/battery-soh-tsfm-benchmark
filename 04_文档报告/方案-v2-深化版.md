### 3.3 SOH 归一与 EOL 定义（v2 关键修正）

**问题**：v1 说"SOH = 容量/初始容量，EOL = SOH 80%"。实测 MIT 数据**在 EOL 处截断**——末点容量恰为额定 1.1 Ah 的 80.0–80.3%，`cycle_life`（1852）≈ 序列长度（1850）。按"穿越 80%"检测真值 EOL，**永远检测不到**，EOL 指标整列报废。

**v2 规则**：
1. **轨迹指标**：SOH = 容量 / 上下文前 5 点中位数 × 100（因果、无泄漏），跨数据集可比。
2. **EOL 真值**：优先用数据集官方标签——
   - MIT：`cycle_life`（cells.parquet 直接有）；
   - NASA / CALCE：SOH 首次 ≤80% 的循环（线性插值）；未到 80% 的 cell **排除出 EOL 统计并注明 n**。
3. **RUL@起点** = EOL 真值 − 起点循环号（MIT 天然可算）。
4. **预测未触及 EOL** 的 cell：记 `eol_hit=0`，不计入 EOL 误差中位数，但**单独报告命中率**——这个指标本身信息量极大（实测三条经典基线命中率均为 0%）。

## 4. 评测协议（v2 可执行版）

### 4.1 切分

- 相对起点：`start = floor(frac × L)`，主设定 frac=0.5；敏感性 0.4/0.6。
- 上下文至少 10 点、预测段至少 5 点，否则跳过（CALCE 短序列会触发）。
- **不做跨 cell 的时间切分**：train/test 是"按 cell 划分"，不是"按循环划分"。

### 4.2 预处理（顺序固定）

1. 排序去重 → 剔 NaN/非正容量；
2. 只保留最长连续段（CALCE 有断测）；
3. 离群点：与前后 5 点滚动中位数相对偏差 >3% 剔除；
4. SOH 归一（前 5 点中位数，**只用上下文**）；
5. 平滑参考线 Savitzky-Golay(11, 2)，**只用于评估，不喂模型**。

### 4.3 推理

- 统一接口：`predict(context, horizon) -> np.ndarray`，输入输出都在 SOH% 空间。
- **递归滚动 H=64**：每次预测 64 步，拼回上下文继续，直到覆盖 horizon。所有模型统一（包括支持任意长度的 Moirai），协议一致优先于模型最优用法，在 limitation 里说明。
- 尺度：喂模型前按上下文做 z-score，输出反归一（Chronos 内置归一，重复做不冲突）。
- 采样类模型固定种子跑 3 次取均值（seed 42/43/44）。

### 4.4 指标

| 层 | 指标 | 说明 |
|---|---|---|
| 轨迹 | MAE / RMSE（SOH%） | 主指标用平滑真值；副指标用原始点真值 |
| 轨迹 | MAPE | 仅参考，接近 EOL 会爆炸 |
| 寿命 | EOL 绝对误差（循环） | 只统计真值 EOL 可用的 cell |
| 寿命 | RUL@起点误差 | 同上 |
| 诊断 | **EOL 命中率** | 预测是否触及 80%（v2 新增，区分度最高） |

聚合：每格报 **中位数 + 均值 + IQR + n**（延续 Severson 的中位误差口径）。
